# C2 home 3D

小户型公寓的全屋 3D 设计页（three.js r128，单文件 HTML），用 GitHub Pages 发布。

| 页面 | 说明 |
|---|---|
| `index.html` | C2 - 家具（主设计，已发布版，2026-10-25） |
| `carpentry.html` | 定制家具：柜内结构、尺寸、图纸 |
| `lighting.html` | 灯光 |
| `walk.html` | 动线漫游 |
| `mobile.html` | 手机预览 |
| `main-design/` | **主设计最新源文件和构建脚本（2026-10-27，未发布）**，接手请先读 [main-design/HANDOVER.md](main-design/HANDOVER.md) |
