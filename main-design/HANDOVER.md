# C2 主设计：交接说明

这是一套小户型公寓的全屋 3D 家具设计页（three.js r128，单个 HTML 文件）。前一个 AI 一直用它跟业主一起定方案。本文件夹是 **2026-10-27 的最新主线**，没有发布成首页。

- 公开首页 `../index.html` 还是 2026-10-25 的版本（6d13ea9）：乐园沙发，默认是业主的组合A。
- 本文件夹比首页新，包括去掉乐园沙发、新沙发探索、组合B、书柜门 550 等改动。还没定稿，所以首页没换。
- 预览地址（GitHub Pages）：`https://kaguravicky-web.github.io/home-3d/main-design/c2-living-free.html?lang=zh`

和业主沟通用中文，有话直说，给诚实意见。

| 文件 | 作用 |
|---|---|

| `free_mode.js` | 自由摆放层（`const FREE = (() => {...})()`）。客厅家具库、拖动/旋转、组合A/B/C、默认布局、沙发布料系统都在这里。 |

| `c2-living-free.html` | **构建结果**，就是"C2 - 家具"页面。three.js 从 jsDelivr CDN 加载。 |
| `inline_three.py` + `vendor_three128/` | 把 three.js 内联进去，得到离线单文件版 `C2 - 家具.html`。发布到首页的就是这个单文件版。 |

以前的修改都是一次性的 Python 补丁脚本（free_vNN.py、fix_*.py），直接改源文件。补丁脚本没放进来，只有改完的结果。

## 2. 构建和预览

```bash
cd main-design
python make_free.py .                    # -> c2-living-free.html
python js.py c2-living-free.html chk.js && node --check chk.js
python inline_three.py vendor_three128 c2-living-free.html "C2 - 家具.html"   # 单文件版
python render_server.py 8766 renders     # 打开 http://localhost:8766/c2-living-free.html?lang=zh
```

make_free.py 有几条容易踩的规则：
- 每个 `rep()` 都 assert 原文只出现一次。改了 c2-living-3d.html 里被替换的那几行，构建就会失败。
- 中文检查（第 170 行起）：面板和 free_mode.js 里出现的中文字符串，都必须在翻译表里，否则构建失败。新文字要在 `NEW` 表里补上 EN 和 KO，页面会用 MutationObserver 自动翻译。
- 只有整行注释（以 `//` 开头）可以写中文。代码后面的行尾注释写中文会被当成没翻译。含中文的行里也别用英文撇号（如 `planter's`），它会把字符串切断。
- 跑的时候把输出存下来再看最后一行（`python make_free.py . > mf.log; tail -1 mf.log`）。直接用管道接 tail 会把失败吞掉。

**发布到首页（只在业主说"推"的时候做）：** 把单文件版复制成 `../index.html`。先查公开文件里没有楼盘名和地址（业主会告诉你楼盘名，不要写进仓库）。commit 作者用 GitHub noreply 邮箱，不要用业主的私人邮箱。

## 3. 代码结构要点

**坐标**
- 全部用毫米。`MM = 0.001`，层高 `H = 2.8`。墙体数据在开头的 `const S = {"walls": ...}`。
- 沿窗一排房间（x）：主卧 0–2600，儿童房 2900–5240，书房 5340–7780，客厅 7995–10700。
- 客厅：沙发墙（光纤墙）x 7995，书房墙 x 10700，玻璃 y 1830，**客厅边界线 y 5100**（书房墙尽头，再往里是餐厅）。
- 玄关在 x 5850–8165、y 8095–11880 一带。

**客厅镜像**
- 客厅家具都在 `livMir` 组里，可以绕 x 9347.5（`LIV_XC`）左右镜像，由 `state.lmir` 控制，取值 'R' 或 'L'。
- 自由摆放的 wrapper 旋转为正时，俯视图里是顺时针。

**状态和面板**
- 全局 `state = {...}`（约第 1777 行）存所有选项。`applyLiving()` 和 `hook(f)` 注册的函数负责把状态应用到模型上。
- 视角：`VIEWS`、`setView(name)`、`LIV_VIEWS`。
- 翻译：`EN` / `KO` 两张 JSON 表，加上 `trTree()`。
- 墙体透明/实心：`state.wallv` 和 `fadeWalls()`。
- 面板只有一个：左边的 `#dock`，里面是 `#sheet`、`#viewbar`、`#freeBox`。新选项都放进这个面板，不要重复做一行。每个页面都要能切中文/EN，也要能切透明墙/实心墙。

**free_mode.js**
- `CAT`：家具库条目，常用字段有 `k`、名称、`dim`、`spawn`，以及几个标记：
  - `frame`：模型自带坐标系；
  - `deco`：放在别的家具上面；
  - `floor`：铺在地上；
  - `wall` + `art`：挂墙；
  - `cols`：黑/白可选；
  - `fab`：沙发布料系统。
- `LIB_G`：库的分组。`LIB_GONE`：删掉的条目（旧存档里的会被映射成别的）。`BY`：按 key 查条目。
- `BUILTIN.A/B/C`：内置组合。**C 是发布的默认**。组合里存 `pieces`（x/y 毫米、a 弧度、h 高度、c 颜色），以及 `opts`（其他房间的选项）、`dine`、`dcount` 等。
- `sane()`：把旧的或已删除的选项映射成现在合法的值。`OPT_KEYS`：哪些 state 会跟着组合一起保存。
- 存储用 localStorage：`c2free.v2`（当前布局）、`.def`（这个浏览器的默认）、`.slots.v1`（组合）、`.opts`、`.dine`、`.hstool`、`.hrug`、`.sheer`、`.lock`。
- 页面在 `window.FREE_HIDE = true` 下（各工种页面用）会隐藏面板，直接显示 BUILTIN C。

**沙发布料（fab）**
- 每个网格都有 `userData.role`（'seat' 或 'back'）和 `uvk`（'m' / 'sph' / 'box'）。
- `applyFab(w, 'white|lemon|blue' + 可选 '|seat' 或 '|back')` 给沙发上色，后缀表示蓝白 ikat 图案放在坐垫还是靠背。
- 颜色：白 #eee9e0，浅柠檬黄 #f5e9a2，浅蓝 #bcd0e2。ikat 图案用 canvas 画。

**渲染注意**
- r128 + sRGB 输出时，直接写的十六进制颜色渲染出来偏浅；贴图（sRGB）的颜色比较准。
- 后台标签页不跑 requestAnimationFrame。测试要截图的话，自己开一个 `new THREE.WebGLRenderer` 离屏渲染。

**测试别动业主的数据**
- 业主可能开着页面在摆家具，localStorage 里存着他们的布局和组合。
- 测试用自己的新标签页，不要点"设为默认/保存/恢复默认"，也不要清存储。
- 可以先用 `Storage.prototype.setItem = () => {}` 禁止写入，然后只调 `FREE.load` / `FREE.add` 测。

## 5. 业主的偏好（重要）

**空间**
- 小房子：家具能缩 10–20% 占地的就缩，先缩进深。说清楚缩了多少、还能放下什么。
- 客厅家具不超过 y 5100 边界线（业主自己放过的例外保留）。

**装饰**
- 透明玻璃小花瓶 + 一枝紫色兰花，到处用这一种。
- 植物只留散尾葵。新鲜的高枝条可以，枯枝不要。
- 不要粗陶、洞石。树瘤木只用一点点。

**地毯**
- 业主掉头发，新加坡又潮，不喜欢绒毛地毯。只做可洗的平织款，而且默认不放。
- 地砖不要画砖缝（"看起来像厕所"）。

**商品图和业主自己的东西**
- 椅子、凳子的商品图：业主一般选黑白款，别的颜色只是给你看尺寸用的。如果截图里选中了某个颜色，或者业主说了颜色，就按那个颜色做。
- 不要替换业主自己的东西。比如主卧电视是 LG OLED 配银色 V 字架。业主画的草图是告诉你摆放位置，不是要换产品。

**客厅限制**
- 客厅不放电视。
- 路由器留在光纤插座那里。业主不打孔、不改线。

**其他**
- 不做价格和预算分析，预算另有台账。
- 每次改完给本地链接和对比图。业主说"推"才发布到 GitHub 首页。现在的沙发属于早期探索，不要老问要不要推。

## 7. 业主的灵感方向（想法库摘要）

业主收藏的参考图有几个共同点：
- 白墙或很浅的墙；
- 一个主色（蓝或黄）配白；
- 天然材质：剑麻、藤、木；
- 一点绿；
- 一件有图案的软装（青花、ikat、条纹）；
- 装饰件数少，但每件都够大。

客厅缺的正是"一个主色"和"一处图案"，所以在试彩色沙发和蓝白图案。
